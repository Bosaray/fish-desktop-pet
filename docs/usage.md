# 日常使用

右键鱼鱼或系统托盘图标可打开菜单。

|入口|用途|
|---|---|
|和鱼鱼玩|泡泡、玩球、收玩具、收藏展示、回小窝、取食|
|摆放道具|把小窝和零食盒放到附近，或切换显示|
|桌宠设置|大小、屏幕、置顶、音效、鼠标穿透、桌面交互与连接权限|
|暂停自主活动|暂停随机选择；再次选择恢复|
|停止当前动作|停止动作并释放正在控制的鼠标|
|找回鱼鱼|找回角色并置顶|

拖动角色、小窝、零食盒调整位置。点击零食盒补货，8份装满后自动收起面板。不要同时运行多个连接同一设备的桌宠实例。

完整QQ联动需要配套服务端，当前首次配对方法还在整理。全屏游戏、多屏和拖动在不同环境下仍需验证；遇到问题请记录版本与步骤后提交Issue。
